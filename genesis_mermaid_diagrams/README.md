# Genesis Mermaid Diagrams Source Code

This folder contains the raw Mermaid source code (`.mmd` files) for all six system diagrams created for the Genesis presentation. 

You can copy-paste these codes directly into markdown slides or edit them using the Mermaid live editor (mermaid.live).

## File Index
1. `diagram_1_loop.mmd` - High-Level Conceptual Loop
2. `diagram_2_agent.mmd` - Agent Architecture (CPPN + NEAT + Cost)
3. `diagram_3_env.mmd` - Environment Physics (Gray-Scott + Secretion)
4. `diagram_4_select.mmd` - Selection & Regulation flowchart
5. `diagram_5_poet.mmd` - Co-evolutionary Orchestrator Sequence
6. `diagram_6_system.mmd` - Full Stack Layered Integration
